# PromptMotion - 2D Animation Platform

PromptMotion is a modern web application that enables users to create and manage 2D animations. The platform consists of a React-based frontend, a Python backend, and Firebase integration for data management and authentication.

## Project Structure

```
bolt/
├── frontend/          # React + TypeScript + Vite app
├── backend/           # Python FastAPI app (Gemini + Manim)
└── firebase/          # Realtime Database security rules
```

## Prerequisites

- Node.js (v18 or higher)
- Python 3.11+
- ffmpeg and a LaTeX/Cairo toolchain (required by Manim — see the Dockerfile for the exact packages)
- Firebase project (Auth + Realtime Database + Storage)
- Docker (optional, for containerised deployment)

## Frontend Setup

The frontend is built with React, TypeScript, and Vite.

1. Navigate to the frontend directory:
   ```bash
   cd bolt/frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create `.env`:
   ```bash
   VITE_API_URL=http://localhost:8000
   VITE_FIREBASE_API_KEY=...
   VITE_FIREBASE_AUTH_DOMAIN=...
   VITE_FIREBASE_PROJECT_ID=...
   VITE_FIREBASE_STORAGE_BUCKET=...
   VITE_FIREBASE_MESSAGING_SENDER_ID=...
   VITE_FIREBASE_APP_ID=...
   VITE_FIREBASE_DATABASE_URL=...
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

The frontend will be available at `http://localhost:5173`

## Backend Setup

The backend is built with Python and FastAPI.

1. Navigate to the backend directory:
   ```bash
   cd bolt/backend
   ```

2. Create a virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Create `.env` (see `config.py` for every supported key):
   ```bash
   GEMINI_API_KEY=...
   FIREBASE_DATABASE_URL=https://<project>-default-rtdb.firebaseio.com/
   FIREBASE_STORAGE_BUCKET=<project>.firebasestorage.app
   RAZORPAY_KEY_ID=...            # optional; billing is disabled without it
   RAZORPAY_KEY_SECRET=...
   RAZORPAY_WEBHOOK_SECRET=...
   CORS_ORIGINS=http://localhost:5173
   DEV_MODE=false
   ```

5. Start the backend server:
   ```bash
   python main.py          # or: uvicorn main:app --reload
   ```

The backend API will be available at `http://localhost:8000`

## Firebase Setup

1. Create a new Firebase project in the Firebase Console.
2. Download your service account key and place it in `bolt/backend/serviceAccountKey.json`,
   or set `FIREBASE_SERVICE_ACCOUNT_JSON` (raw JSON) / `FIREBASE_SERVICE_ACCOUNT_FILE` (path)
   for hosted environments.
3. Deploy `bolt/firebase/rules.json` to the Realtime Database. The rules make
   `accountType`, `subscription`, `dailyUsage`, `usage_stats` and `metrics`
   server-writable only — clients can read them but never grant themselves a plan.

## API Documentation

### Main Endpoints

All endpoints require a `Authorization: Bearer <Firebase ID token>` header.

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/health` | Liveness probe |
| `POST` | `/generate` | Generate and render an animation from a prompt |
| `GET` | `/code/{scene_file_id}` | Fetch the Manim source for an animation |
| `PUT` | `/code/{scene_file_id}` | Replace the source and re-render |
| `GET` | `/my-codes` | List the caller's animations (summaries) |
| `GET` | `/usage-stats` | Quota and lifetime render totals |
| `GET` | `/recent-activity` | Ten most recent animations |
| `GET` | `/metrics?days=7` | Render latency/success aggregates |
| `POST` | `/api/create-razorpay-order` | Start a subscription for the caller |
| `POST` | `/api/cancel-subscription` | Cancel and downgrade to free |
| `POST` | `/api/razorpay-webhook` | Razorpay callback (HMAC-verified) |

For detailed API documentation, visit `http://localhost:8000/docs` when the backend server is running.

## Security notes

- Scene code is generated by an LLM and editable by users, then executed by the
  Manim CLI. `code_validator.py` screens it with an import allowlist, but that is
  hardening, not a sandbox — run the renderer in an isolated container with no
  credentials mounted if you expose this publicly.
- Plan entitlements are granted only by the Razorpay webhook on the server.
